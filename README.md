 Marketing Campaign Analysis -

 PROJECT OVERVIEW:
This project analyzes marketing campaign data to evaluate campaign performance, platform effectiveness, costs, and revenue.
The objective is to use data to identify high-performing campaigns and platforms and understand where marketing efforts can be improved.

TOOLS USED:
Excel – Data cleaning and analysis
SQL– Data analysis and KPI calculations
Power BI – Dashboard and data visualization

 DATASET:
The dataset contains information about different marketing campaigns, including:
* Campaign and campaign date
* Platform
* Target audience
* Impressions and clicks
* Leads, applications, and enrollments
* Campaign cost and revenue
* CTR, CPL, CPC, and CPM
* ROAS and ROI

 BUSINESS OBJECTIVE:
The main objective of this project was to understand how different marketing platforms and campaigns performed based on their cost, revenue, and key performance metrics.
The analysis helps identify better-performing platforms and campaigns and provides a clearer view of where marketing spending is more effective.

PROJECT OUTCOME:
An interactive Power BI dashboard was created to compare campaign and platform performance. The dashboard allows users to filter the data by campaign type, target audience, and platform and easily compare important marketing metrics.

This project demonstrates practical skills in:

Excel Data Cleaning → SQL Analysis → KPI Analysis → Power BI Visualization → Business Insights
