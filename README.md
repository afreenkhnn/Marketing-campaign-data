MARKETING CAMPAIGN ANAIYSIS-

 PROJECT OVERVIEW:
This project analyzes marketing campaign data to understand campaign performance, platform effectiveness, costs, and revenue.
The objective is to compare different campaigns and platforms using key marketing metrics and understand where marketing efforts are performing better.

 TOOLS USED:
Excel – Data cleaning and analysis
SQL – Data analysis and KPI calculations
Power BI – Dashboard and data visualization

 DATASET:
The dataset contains information about different marketing campaigns, including:
Campaign and campaign date
 Platform
Target audience
Impressions and clicks
Leads, applications, and enrollments
Campaign cost and revenue
 CTR, CPL, CPC, and CPM
 ROAS and ROI

BUSINESS OBJECTIVE:
The main objective of this project was to understand how different marketing platforms and campaigns performed based on their cost, revenue, and key performance metrics.
The analysis was used to compare campaign performance, understand marketing spending, and identify platforms and campaigns that performed better.

PROJECT WORKFLOW:
Excel → SQL → KPI Analysis → Power BI

Excel – Cleaned and prepared the campaign data for analysis.

SQL – Analyzed the data and calculated key marketing metrics.

Power BI – Created an interactive dashboard to compare campaign and platform performance.

PROJECT OUTCOME:
An interactive Power BI dashboard was created to provide an overview of campaign performance. The dashboard allows users to filter the data by campaign type, target audience, and platform and compare important marketing metrics.

This project demonstrates practical skills in:
Excel Data Cleaning → SQL Analysis → KPI Analysis → Power BI Visualization → Business Insights.
